# React Quote App

A simple and interactive quote generator built with React and Vite. Discover random quotes, save your favorites, and manage your personal collection through a clean and responsive interface.

## Features

- **Random Quotes:** Fetch random quotes using the DummyJSON Quotes API.
- **Favorites:** Save quotes you particularly like.
- **Duplicate Prevention:** Prevents adding the same quote and author more than once.
- **Favorites Panel:** View all saved quotes in a dedicated panel.
- **Remove Favorites:** Delete individual quotes from your favorites.
- **Interactive UI:** Toggle the favorites panel and generate new quotes with simple button interactions.

## Technologies Used

- React
- JavaScript (ES6+)
- Vite
- CSS3
- React Hooks (`useState`)
- DummyJSON Quotes API
- Boxicons

## API

This project uses the [DummyJSON Quotes API](https://dummyjson.com/quotes/random) to retrieve random quotes.

No API key is required.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Martynas-Mockapetris/React-Quote-Generator-APP.git
```

### 2. Navigate to the project directory

```bash
cd React-Quote-Generator-APP
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
