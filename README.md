# React Quote App

A simple and interactive quote generator built with React and Vite. The app allows users to discover random quotes, save their favorites, and manage their personal collection through a clean and interactive interface.

## ✨ Features

- **Random Quotes** — Fetch random quotes using the DummyJSON Quotes API.
- **Favorites** — Save quotes you particularly like to your personal collection.
- **Duplicate Prevention** — Prevents adding the same quote and author more than once.
- **Favorites Panel** — View saved quotes in a dedicated favorites panel.
- **Remove Favorites** — Delete individual quotes from your favorites collection.
- **Interactive UI** — Toggle the favorites panel and generate new quotes using interactive buttons.

## 🛠️ Technologies Used

- **React** — Component-based UI development.
- **JavaScript (ES6+)** — Quote handling, API requests, and application logic.
- **Vite** — Development server and production build tooling.
- **CSS3** — Custom styling, layouts, transitions, and visual effects.
- **React Hooks** — `useState` for managing quote data, favorites, and panel visibility.
- **DummyJSON Quotes API** — Retrieves random quotes and author information.
- **Boxicons** — Icons for favorites, quotations, and interface controls.
- **Git & GitHub** — Version control and source code hosting.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Martynas-Mockapetris/React-Quote-Generator-APP.git
   ```

2. Navigate to the project directory:

   ```bash
   cd React-Quote-Generator-APP
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided in your terminal, typically `http://localhost:5173`.
